# Jarvis Offline — Android-проект (исходники)

Проект для Android 10+ (minSdk 29), без разрешения INTERNET. Подходит как стартовая основа для локального помощника на Redmi 9A.

## Реализовано в исходниках
- локальная SQLite-база: заметки, задачи, журнал и напоминания;
- создание/просмотр/удаление заметок и задач;
- создание напоминания с выбором даты и времени;
- системный `AlarmManager` с `setExactAndAllowWhileIdle` для точных напоминаний;
- уведомление со звуком/вибрацией на заблокированном экране (если разрешено системными настройками);
- восстановление будущих напоминаний после перезагрузки и изменения времени;
- приложение не запрашивает доступ к интернету.

## Важно: это ещё не полноценный Джарвис
В проект пока НЕ встроены языковая модель, офлайн-распознавание речи, активационное слово и непрерывный голосовой диалог. Текстовые команды распознаются простыми правилами. Это исходный проект/прототип планировщика, не готовый APK и не готовая GGUF-модель.

Для полноценного офлайн-помощника нужны отдельные компоненты:
- офлайн STT (например, Vosk с русской моделью);
- локальный LLM runtime (например, llama.cpp через JNI) и совместимая GGUF-модель;
- офлайн TTS-голос, установленный на устройстве;
- безопасный слой команд с подтверждениями для действий, затрагивающих данные или приложения.

На устройстве с Android 10 и 2 ГБ RAM постоянная фоновая работа и свободный голосовой диалог могут быть ограничены системой и батареей. Для напоминаний включите для приложения автозапуск/разрешённые уведомления и снимите ограничения энергосбережения в MIUI, если они мешают. Даже тогда нельзя гарантировать срабатывание при выключенном телефоне, разряженной батарее или принудительной остановке приложения.

## Сборка
Откройте папку проекта в Android Studio, установите Android SDK Platform 35 и совместимый Android Gradle Plugin 8.6.1/JDK 17 или 21, затем выберите Build > Build APK(s). APK в архив не включён: в этой среде нет установленного Android SDK/Gradle, поэтому сборка и тест на устройстве не выполнены.
